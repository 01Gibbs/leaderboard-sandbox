Connect to GitHub

The forms start the leaderboard's facilitator workflows on GitHub, as you. That needs a token, made once:

  1. Open a new fine-grained token.
  2. Repository access: Only select repositories → this leaderboard.
  3. Permissions: Actions: Read and write and Contents: Read-only. Nothing else.
  4. Generate it, copy it, and paste it here.

The token stays in this browser and is sent only to GitHub.
